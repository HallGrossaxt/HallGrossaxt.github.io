A Passion Project for Fun

PICLas is an open-source framework for kinetic plasma and rarefied gas flows, combining Particle-in-Cell (PIC) and Direct Simulation Monte Carlo (DSMC) methods. Like most HPC codes, it is built for Linux clusters.

My focus is making that whole toolchain first-class on Windows: portable MSYS2 / UCRT64 (GCC) builds with MS-MPI and optional CUDA/GPU support, self-contained release bundles that run on a clean machine, and a regression-tested port of the supporting tools — the mesh generator and the test framework. The goal is simple: lower the barrier to running serious simulation work without leaving Windows.
